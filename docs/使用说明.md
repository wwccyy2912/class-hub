# 2028届1班信息资源共享网站

网站：https://class-hub-sep27-2026.d781425787878.chatgpt.site

每位同学使用独立账号登录。普通成员可以阅读和下载资料，管理员还可以上传资料和管理账户。

## 界面速览

- 顶部导航：首页 · 资料站点（点开是全部站点的下拉列表，前面的小圆点区分类型）· 日历 · 课程表 · 管理后台 · ＋新建（管理员）· 你的名字（账户）· 退出；最右边的 ⚙ 是偏好设置（外观与播放开关）。手机上是右上角的菜单按钮。
- 管理后台：分成「资料与账户 / 站点管理 / 课程表 / 日历与事件」四个标签页；课程表和日历页对普通成员是只读的，管理员可以在页头点“编辑课程表 / 编辑日历与事件”直接跳到后台对应标签。

## 功能入口与开关

- **首页入口磁贴**：登录后首页右上角是常用入口磁贴（课程表、日历、每个专题站点；管理员还会多一个“上传资料”）。入口超过 6 个时，最后一块变成“全部站点”，点它就跳到页面下方的“专题站点”区块。
- **主按钮跟着站点走**：首页标题下的第一个按钮指向你的第一个专题站点（例如“进入班级相册”），站点改名或新建后按钮会自动跟着变，不会指向不存在的地址。
- **未登录页面**：只显示登录框，并在下面用四条简介说明站内有什么（课程表提醒、日历与调休、资料预览下载、相册与媒体播放）。
- **管理员「＋新建」快捷入口**：顶部导航的“＋新建”里可以直接开始：上传资料 / 新建站点 / 创建班级账户 / 编辑课程表 / 日历与事件。点进去会打开管理后台对应的标签页，并自动把光标放到要填写的输入框。
- **⚙ 偏好设置**（登录前后都能用，设置只保存在你自己的浏览器里）：
  - 网络与流量：**自动 / 省流 / 标准 / 高清**。默认“自动”，会根据浏览器上报的网络类型（4G/3G/省流开关）和实测延迟自动选择；面板下面会写明判定依据（例如“自动判定：标准 · 4G · 下行 1.6 Mb/s · 延迟 100 ms”）。省流档下：相册网格用缩略图、视频不预载、超过 1.2 MB 的大图先显示缩略图并提供“加载原图”按钮、不做预取；标准/高清档会把鼠标悬停的入口提前取回数据，翻页更快。
  - 外观：跟随系统 / 浅色 / 深色，选过就记住，下次打开不会闪一下白屏。
  - 进入媒体页自动播放：打开音频/视频时是否自动开始（部分浏览器会拦截自动播放，需要手动点一下）。
  - 播完自动下一个：音频/视频播放结束后是否自动接着播放列表里的下一项。
  - 显示快捷键提示：播放器下方的快捷键说明是否显示。
- **账户开关**：管理后台“账户与权限”里，每个账号右侧的“使用中 / 已停用”是一个开关按钮，点一下即停用或启用；停用、启用、改权限、重置密码都会让该账号已经登录的会话立即失效。主管理员账号受保护，不能被停用。

## 浏览器标签页图标

网站的标签页图标（favicon）现在由同一套文件生成：PNG（16/32/48/192/512）、favicon.ico 和一份不含文字的矢量图，Firefox 与 Chrome 显示完全一致。如果之前打开过网站、标签页还显示旧图标或空白，请**强制刷新**（Windows/Linux 按 Ctrl+F5，Mac 按 Cmd+Shift+R）或关闭标签页重新打开——浏览器会缓存图标很久。

## 第一次打开网站

全新部署（或清空数据库后）第一次打开网站，看到的是**初始化页面**，不是登录页：

1. 填写 **学校名称**、**班级名称**（可选填网站副标题）；
2. 设置 **管理员账号**（3–32 位字母、数字或 . _ -，不能用 admin）和 **密码**（至少 12 个字符，输两次）；
3. 点“完成初始化并进入网站”，你会直接以管理员身份进入网站，页头、标题、页脚立刻显示你填写的学校与班级。

初始化只能做一次；之后打开网站就是正常的登录页。这些信息以后都可以在「管理后台 → 网站信息 / 账户与权限」里修改。

## 管理员开始使用

0. **网站信息**：管理后台「资料与账户」最下面的“网站信息”里可以改**学校名称、班级名称、网站副标题**，保存后页头、登录页、浏览器标题、首页大标题和页脚会一起更新（不用重新部署）。不填学校名称时，页头只显示班级名称和副标题。
1. 打开同目录的“管理员初始账户.txt”，使用其中账号（admin）和初始密码登录。
2. 按提示修改为自己的密码（至少 12 个字符）。首次登录必须完成这一步，否则不能查看资料。
3. 点击“管理后台”。
4. 在“上传资料”中：填写文档标题，选择“所属站点”（不同站点能上传的格式不同，输入框会自动提示），选择文件，等待预览与大纲生成，检查无误后勾选“我已检查页面显示与文件内容”，再点“上传并保存”。
   - 图册站点可以一次选多张照片：页面会先显示“已转 WEBP”的预览，再一起上传。
   - PDF：可以逐页预览、缩放，页面会按书签或正文标题生成大纲。单个文件不超过 20 MB、500 页。
   - Word / Excel / PowerPoint（.doc .docx .xls .xlsx .ppt .pptx）：保存原文件，成员下载后用 Office 或 WPS 打开；这类文件不在线预览排版。
5. 在“专题站点”中可以新建资料子站：填写站点名称、访问路径（小写字母、数字或 -，例如 activity）、**站点类型**和一句话说明，点“创建站点”。成员在主站首页能看到全部站点；上传资料时选择对应站点，资料就会归到那个站点下。
   - **文件站点**：放 PDF、Word/Excel/PowerPoint、TXT、Markdown。PDF 能在线看并自动生成大纲；TXT/Markdown 能在线看（Markdown 会排版）；Office 文件只能下载。
   - **文件夹站点**：只放 ZIP 压缩包。上传后同学能直接在网上浏览压缩包里的文件、预览文本和图片、单独下载某个文件，也可以整包下载。
   - **图册站点（媒体库）**：放照片、视频和音频。照片上传时自动转成 WEBP（更省空间），可以一次选多张；进入某一张后就是自带播放器：进度条、音量、倍速、循环、自动下一个，图片还能缩放、旋转、自动轮播，点“下载 PNG”会转成 PNG 再保存。视频可以在线播放（支持全屏和画中画），音频有实时频谱；右侧播放列表可以直接切换到同站点里的其它媒体。
     - 支持的视频：mp4 / m4v / mov / webm / mkv / avi / wmv / flv / mpg / mpeg / ts / m2ts / 3gp / ogv；音频：mp3 / m4a / m4b / aac / wav / ogg / oga / opus / flac / weba / mka / wma / amr / aif / aiff / ac3 / mid。
     - 能不能在线播放取决于浏览器自身的解码能力：浏览器能解码就直接播放；不能解码（例如有些 wmv、老式 avi）页面会写明“当前浏览器不能直接解码”，并提供“下载原文件”和“尝试播放”两个按钮，下载后用本地播放器即可打开。
   - 类型在创建时选；站点里还没有资料时可以改类型，已经有资料就不能再改了。
   - 网站默认不预置任何站点，需要管理员自己创建；新站点创建后会立刻出现在主站首页和顶部导航里。
   - “编辑”可以改站点名称和说明；“查看”打开站点页面；站点里还有资料时不能删除，需要先把里面的资料清空。
   - 访问路径会出现在网址里（如 https://…/sites/activity/），创建后不能修改。
6. 在“用户组”里可以先把常用权限组合成组（勾选：上传与管理资料 / 站点管理 / 账户与用户组 / 课程表 / 日历与事件 / 网站信息），点“新建用户组”；之后点组名右侧的“编辑”可以改组名、说明和权限，**改完会同步给组内所有成员**。
7. 在“创建班级账户”中填写账号、姓名、初始密码，然后选择：
   - **用户组**：下拉里选一个组，这个账号就拥有该组的全部权限；
   - **不使用用户组（手动指定权限）**：自己勾选这个账号需要的权限；
   - 勾选“设为管理员（拥有全部权限）”则拥有全部权限（等同现有管理员）。
   把账号和初始密码告诉同学，同学首次登录需要自己改密码。
8. 在“账户与权限”中可以：给账号换用户组（下拉框）、设为管理员/成员、停用/启用（开关按钮）、重置密码、**删除账号**。停用、改权限、换组或重置密码后，该账号已经登录的会话会立即失效。
   - **删除账号**：点“删除账号”并确认即可。删除时会一起清掉这个账号的登录会话、聊天已读记录，以及**他发过的聊天消息和附件**（他上传的资料会保留）。不能删除自己，也不能删除名为 `admin` 的主管理员账号。
   - 被停用的同学登录时会看到「这个账号已被管理员停用，请联系班级管理员」，而不是笼统的“密码不正确”。
   - 普通成员（没有任何管理权限）只能阅读和下载，看不到“管理后台”入口；有部分权限的账号在后台只会看到自己有权限的标签页和面板。
8. 打开顶部导航的“课程表”，在“课程维护”里按星期、开始节次填写科目、老师、教室和时间；连堂课在“连堂节数”里填 2–4，单双周的课在“周次”里选择。保存后首页的“今天 / 明天 / 后天”提醒会立即更新。
   - 在“学期与提醒设置”里填“学期开始日期（第 1 周第一天）”，单双周就会按教学周计算（页面上会显示“第 N 周”和确认预览）；不填则按自然周计算。同一栏还可以调整倒计时窗口（默认 14 天）和最多显示几条（默认 3 条）。
   - 整张课表可以一次导入：在“批量导入课程表”里从 Excel 复制粘贴（或按`星期, 开始节次, 科目, 老师, 教室, 开始时间, 结束时间, 周次, 连堂节数`的顺序输入，后面几项可以省略），先点“解析预览”确认，再点“导入课程表”。需要重排整张表时勾选“导入前清空现有课程表”。
9. 打开顶部导航的“日历”，可以看到法定节假日（标「休」）和调休上班日（标「班」）。页面上有“立即同步官方数据”，也可以在下面为学校自己的安排覆盖某一天（例如“校运会”放假）。
   - 在“自定义事件”里可以添加开学、期中/期末考试、运动会、家长会等日期；它们会出现在首页的“近期假期”倒计时里，也会在月历上标出，之后可以随时编辑或删除。
   - 调休上班日可以在“调休按哪天课表”里指定按星期几上课（默认：周六调休按周五课表、周日调休按周一课表），课程表和提醒都会照此显示。

## 聊天

- 顶部导航点「聊天」进入：左边是会话列表——最上面是**班级大群**（所有同学都能看到），下面是和每一位同学的**私聊**（只有你们两个人能看到，别人点进去看不到内容）。
- 点会话开始聊；输入框里按 **Enter 发送**、**Shift+Enter 换行**，一条最多 500 字。有未读消息时会话后面和顶部导航都会显示红色数字。
- 别人的新消息不用刷新页面就会自己出现（正常网络 4 秒一次、省流模式 10 秒一次；切到其它标签页时会暂停，回来立刻刷新）。
- 自己发的消息，鼠标移到气泡上点右上角 ✕ 可以删除；管理员（或有「账户与用户组」权限的同学）可以删除任何人的消息。
- 往上翻可以看到更早的消息（点「加载更早的消息」）；消息数量多时只加载最近的部分。
- 点输入框左边的 📎 可以发一张图片或一个文件（最大 10 MB）：图片会直接显示在对话里，其它文件显示成可点击下载的卡片；发送前会显示附件名字，点 ✕ 可以取消。
- 想提醒某位同学，输入 `@` 会跳出候选人，选中后写上内容即可（例如 `@李同学 明天带跳绳`）；被 @ 的同学在会话列表和顶部导航上会看到橙色的 @ 角标。
- 自己发的消息在「撤回时限」内（管理员设置，默认 10 分钟）可以点气泡右上角 ✕ 撤回；超过时限就撤不回了，只能请管理员删除。
- 聊天只在登录后可用；账号被停用、权限被改或被禁言后，原有登录会失效，需要重新登录。
- 被管理员禁言时，输入框会变成灰色并显示「你已被管理员禁言」，仍然可以看到消息；大群和私聊的禁言是分开设置的。
- 管理员可以在「管理后台 → 资料与账户」里对每个账号单独设置「群聊可发言 / 私聊可发言」；在「聊天设置」里可以改撤回时限、历史消息保存天数（默认 90 天，0 表示永久保留），也可以点「立即清理」按小时数手动清理一次历史消息（附件会一起删除）。

## 阅读资料

打开主站首页，会列出全部专题站点，点进去选择要看的文件：

- 左侧大纲可以直接跳到对应页；也可以输入页码、使用“上一页/下一页”。
- “适合宽度”或百分比可以缩放页面；“查看本页文字”可以复制当前页文字。
- 右上角可以下载 PDF 原件，或在浏览器新标签页中打开原文。
- 打开扫描件时页面会提示“未提取到文字”，此时只能逐页翻阅或下载原件（网站不做 OCR）。
- Word / Excel / PowerPoint 资料会显示下载按钮，下载后用 Office 或 WPS 打开。
- 顶部导航会列出全部站点，可以在站点之间直接切换。

## 日历与课程表

- 主站首页最上方是“今天 / 明天 / 后天”三张提醒卡，标题固定带完整日期，例如：明天 2026年9月30日 周三 · 按课表上课，共 4 节；“明天”那张会逐条列出节次（含连堂区间）、科目、老师、教室和时间。
- 更下面的“近期假期”会显示倒计时，例如：2 天后（2026年10月1日 周四）· 国庆节 放假，共 7 天；管理员添加的自定义事件（如“期中考试”）也会一起显示。
- **深浅色**：点页头右侧的 ⚙，在“外观”里选择「跟随系统 / 浅色 / 深色」，选过一次就会记住；默认跟随手机或电脑的系统外观，系统切换时自动跟着变。
- 网站整体是通透的毛玻璃（液态玻璃）风格：面板半透明叠加 30px 模糊、彩色渐变背景、高光与柔和投影，切换页面/悬停/弹窗都有自然缓动动画；跟随系统深色模式，手机上自动单列。
- 明天放假、周末或调休上班时，提醒会相应写成“国庆节放假，明天没有课程。” / “周末休息，明天没有课程。” / “国庆节调休上班，按课表上课”。
- “课程表”页有 7 天概览（今天、明天、后天…）和一周课程网格，方便提前预习准备。
- “日历”页是月历：翻月看整月安排，红色标“休”是放假，橙色标“班”是调休上班，蓝色边框是今天；下面列出本月所有节假日与调休。
- 手机上同样可以看：日历会自动缩小格子并保留节日名称，提醒卡改为上下单列，页面不会横向滚动；课程表可以左右滑动查看整周。

## 限制与注意事项

- 单个文件：视频/音频最大 200 MB（超过 8 MB 会自动分片上传，页面上显示进度百分比和速度），图片、PDF、Office、压缩包最大 20 MB；PDF 最多 500 页。
- 自动大纲以原文为准，长文档请核对后再使用。
- 扫描图片类 PDF 不含可提取文字，无法自动生成大纲。
- 忘记密码请联系管理员重置；重置后首次登录必须重新设置密码。
- 网站入口目前保留原有访问范围。用户确认公开登录入口后，同学才可无需 ChatGPT 打开班级登录页。
- 请勿把“管理员初始账户.txt”或管理员密码转发到班级群里。
